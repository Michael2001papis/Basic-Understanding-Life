חלק ב: סיכום מנהלים
----------------------------------------

פרויקט: אתר תוכן SPA בעברית – "להיות שם באמת" – מדריך רגשי־אנושי לזוגיות ולהורות.
מטרה: להסביר נוכחות אמיתית ברגעי קושי, לגשר בין צד פגוע לצד שלא תמיד מבין, לשלב חידונים
וסיטואציות אינטראקטיביות.

סטאק: React 19, TypeScript 5.9, Vite 8. עיצוב: CSS גלובלי עם משתנים (theme, ניגודיות, גודל טקסט).
אין בסיס נתונים – הכל קליינט, כולל שמירת state ב-localStorage.

מספר קבצים עיקריים: כ־41 (כולל config, HTML, CSS). רכיבי React: 22+ (layout 3, sections 14,
shared 2, error 2, maintenance 2, views 1).

src/App.tsx
  - state: currentView (ViewId) מאתחול מ-getInitialViewId() (hash או home).
  - useEffect: סנכרון currentView ל-URL hash (viewIdToHash).
  - useEffect: האזנה ל-hashchange לעדכון currentView.
  - רינדור: AppLayout(currentView, setCurrentView) ו-ViewContent(viewId).

src/viewConfig.ts
  - ViewId: 'home' | 'quiz' | 'scenario-quiz' | 'life-situations' | 'patterns-needs' | 'faq-final'.
  - viewItems: מערך עם id ו-label לכל view (עברית).
  - viewIdToHash(id): "#v-{id}".
  - hashToViewId(hash): מפענח hash, מחזיר ViewId או null.
  - getInitialViewId(): מהדף – hash או 'home'.

src/settingsConfig.ts
  - FontSizePref: 'default' | 'large' | 'small'.
  - ContrastPref: 'normal' | 'brown' | 'blue'.
  - QuickUIPref: boolean (ממשק מהיר – הפחתת אפקטים).
  - SiteSettings: שלושת השדות.
  - SETTINGS_STORAGE_KEY: 'siteSettings'.
  - loadSettings(): קריאה מ-localStorage, ברירת מחדל במקרה שגיאה.
  - saveSettings(): שמירה ל-localStorage.
  - applySettingsToDocument(): הגדרת data-font-size, data-contrast, data-quick-ui על documentElement.

src/maintenanceConfig.ts
  - MAINTENANCE_MODE: boolean. true = מסך שיפוצים + משחק; false = אתר רגיל.

חלק יט: מפת ניווט וזרימת משתמש
----------------------------------------

  - כניסה לאתר: pathname / או "" → App. pathname אחר → NotFoundPage.
  - App: hash מפוענח ל-viewId. אין hash או hash לא תקין → home.
  - Header: לחיצה על tab → onNavigate(viewId) → setCurrentView → replaceState(hash) → ViewContent מרנדר תוכן חדש.
  - גלילה: בתוך אותו view (home ארוך או view אחר). back-to-top מופיע אחרי 400px.
  - חידון: כניסה ל-view quiz → QuizSection. בחירת תשובה → הסבר → הבא/סיום. שמירה אוטומטית ב-localStorage.
  - חידון תרחישים: כניסה ל-view scenario-quiz → ScenarioQuizSection. בחירה → הסבר → תרחיש הבא או איפוס.
  - הגדרות: כפתור ⚙️ → פאנל. שינוי גודל/ניגודיות/ממשק מהיר → applySettingsToDocument + saveSettings.
  - Theme: לחיצה על ☀️/🌙 → היפוך light/dark, שמירה ב-localStorage ו-data-theme על html.
